# The Exciting Life of a Rock

A single-page scrolling story for CCT 360 Lab 1.

## Files
- index.html: story and page structure
- style.css: colors, layout, transitions and mobile styles
- script.js: scroll events, text reveal and rock movement
- rock.png: local rock image

Open index.html in a browser. No installation or internet connection is needed.

## How the effect works
Each section has a colored background, a text layer and a rock image. The scroll event checks where each section is on screen. The rock moves a small distance using translateY, at a different rate from its section. Text fades in using opacity and a CSS transition. Movement is disabled when the visitor prefers reduced motion.
